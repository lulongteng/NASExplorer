这次，带来一个重新整理过的版本
之前我在GitHub和论坛分享过NASExplorer，主要用来在安卓手机上访问NAS、查找文件以及直接播放视频。这段时间又反复调整了界面、文件管理入口和播放器操作，于是有了现在的「文件探索者」。
这次不是简单地换个名字或图标，而是围绕“手机上打开NAS更顺手、点开视频更方便”这个目标，整理了首页、设置入口和播放交互。它依然面向日常文件浏览与NAS使用场景，不追求堆砌功能，而是希望常用操作更直观。

一、这一版主要更新了什么
01｜首页更清爽主导航围绕“本地”和“网络”展开，移去原先不常用的资源库入口；顶部快捷区域改成更集中的单页呈现，减少不必要的左右切换。
02｜视觉重新设计主页顶部改为深海蓝至蓝绿色的渐变，并调整波浪轮廓和局部背景；存储、下载、应用、回收站、网络访问等功能的图标资源重新绘制，形成更统一的视觉语言。已精简隐藏的入口不会因为换了图标而重新加回。
03｜视频设置更好找视频设置不再埋在层层设置菜单里，而是在主界面右上角、原菜单旁提供独立入口。进入后返回主界面，减少来回切换的操作路径。
04｜播放器操作继续打磨基于应用原有的ExoPlayer播放能力，集中调整横竖屏、播放控制条、进度、倍速和触控交互，让手机横屏看NAS视频时更顺手。
05｜去掉干扰项对部分首页入口和设置分组进行了精简，也移除了原有的评分提示弹窗，尽量把屏幕留给真正需要的操作。
二、NAS文件浏览，保留熟悉的使用方式
连接方面，继续围绕SMB和WebDAV两种常见方式使用NAS。在局域网内可以按自己的设备和账号配置SMB；外网场景可结合已经部署好的WebDAV地址及网络环境使用。它并不是输入飞牛ID就能免配置直连的工具，远程访问仍需要用户准备可用的服务和连接条件。
进入目录后，保留文件夹层级浏览、列表与缩略图视图、排序等实用操作。平时找文档、整理文件夹、浏览图片，不需要每次换一套使用方式。NAS文件与手机之间的上传、下载也是继续保留的重点能力。
配图说明｜当前文档已插入新版主界面截图，可作为网络连接入口和首页结构的辅助展示；若后续补充NAS文件夹浏览截图，可替换到此处。
三、内置播放器，是我很想保留的重点
我自己最常见的使用场景，是在NAS目录中看到一个视频就直接点开播放，而不是反复在文件管理器与其他播放器之间切换。所以文件探索者继续保留内置播放器，并针对手机触控操作作了比较集中的调整。
播放体验提供播放/暂停、进度拖动、上一集/下一集、全屏、画面比例、字幕及音轨等控制入口，支持按需要进行手动旋转与画面调整。
手势习惯双击屏幕切换暂停与继续；长按可临时使用预设倍速（默认2.0倍），松开后恢复原速度；同时保留亮度、音量、进度等滑动操作与锁定控制。
横屏观看围绕横向视频的全屏体验优化控制条呈现与自动隐藏，让画面尽量少受按钮遮挡；播放器设置中的相关行为可以按个人习惯调整。
播放器目前以ExoPlayer为基础，不宣传成多内核随意切换的播放器。视频格式、字幕、音轨和网络读取表现与文件本身、设备解码能力及NAS网络状态有关。

五、适合哪些使用场景？
如果你和我一样，平时主要用安卓手机连接家里的NAS，想浏览文件夹、传几个文件、看看图片或直接打开视频，那这款工具的定位就比较接近你的需要。它也可以作为一个轻量的手机文件管理入口，但不会承诺替代所有专业同步、备份或远程访问工具。

【分享】自己做了个安卓NAS文件管理工具：NASExplorer，支持SMB/WebDAV，还有内置播放器
最近一直在折腾飞牛NAS，平时用手机访问NAS的次数也不少。有时只是想找个文件、看看图片，或者直接播放NAS里的视频，却经常要在文件管理器、浏览器、播放器之间切来切去。用久了总觉得还能再方便一点，于是趁空闲时间，按自己的使用习惯做了一个安卓小工具，取名NASExplorer。
目前已经能满足我自己一部分日常需求，就发到论坛和大家分享一下，也欢迎有类似需求的朋友交流。先说明一下：这是安卓端应用，不是飞牛NAS系统里的Docker应用，也不是飞牛官方软件。
一、连接NAS：SMB和WebDAV都可以添加
主界面可以保存多个网络连接，需要访问哪一个就点哪一个，不用每次都从头输入地址。比如在家里通过局域网SMB访问NAS，出门后也可以根据自己已经配置好的WebDAV地址访问文件。

二、文件浏览：尽量贴近手机文件管理器的操作习惯
连接成功后，可以像打开本地文件夹一样浏览NAS中的目录。文件夹名称、项目数量、当前位置路径都能直接看到，不用每打开一级目录就重新猜自己到了哪里。

三、内置播放器：不想每次看视频都再跳一个App
这个是我自己比较在意的一点。NAS里放了不少视频，手机端如果还要先打开文件管理器、再交给其他播放器，步骤多了就有点麻烦。所以NASExplorer里集成了视频播放器，希望把“找到视频—点开播放”的过程做得更顺手。
播放界面有进度拖动、播放暂停、全屏、倍速等常用操作，也提供了长按快进、滑动进度灵敏度等可调选项。至少在我自己的使用场景中，这种从文件列表直接进入播放界面的方式更方便。

图6内置视频播放器的播放界面
播放器也专门留了设置页面，可以调整播放速度、底部进度条和部分操作习惯。目前主要以ExoPlayer为基础；其他播放内核和部分播放功能还在逐步完善，具体格式兼容性与播放表现会因视频文件、网络及手机而异。
